# اعتبارسنجی کد ملی

پیاده‌سازی: `src/utils/validation.ts` → `isValidNationalId(raw: string): boolean`
استفاده: `src/components/ui/NationalIdInput.tsx` (هر جای دیگری که کاربر کد ملی وارد می‌کند باید از همین کامپوننت/تابع استفاده کند)

## ساختار

کد ملی شماره‌ای است ۱۰ رقمی که از سمت چپ سه رقم کد شهرستان محل صدور شناسنامه، شش رقم بعدی کد منحصربه‌فرد برای فرد دارنده شناسنامه در شهرستان محل صدور و رقم آخر آن هم یک رقم کنترل است که از روی ۹ رقم سمت چپ به‌دست می‌آید.

## الگوریتم اعتبارسنجی

۱. **نرمال‌سازی طول:** چون رقم اول/دوم کد ملی ممکن است صفر باشد و کاربر آن را وارد نکرده باشد، اگر طول ورودی بین ۸ تا ۹ رقم بود، از سمت چپ صفر اضافه می‌شود تا ۱۰ رقمی شود. طول کمتر از ۸ یا بیشتر از ۱۰ همیشه نامعتبر است.

۲. **رقم تکراری:** کدهایی که تمام ۱۰ رقمشان یکسان است (مثل `1111111111`) نامعتبرند، حتی اگر چک‌سام ریاضی درست دربیاید.

۳. **محاسبهٔ چک‌سام:** ۹ رقم سمت چپ هرکدام در ضریب خودشان (رقم اول×۱۰ تا رقم نهم×۲) ضرب و جمع می‌شوند.

۴. **باقیماندهٔ تقسیم بر ۱۱** محاسبه می‌شود:
   - اگر باقیمانده کمتر از ۲ بود → رقم کنترل باید برابر همان باقیمانده باشد.
   - اگر باقیمانده بزرگ‌تر یا مساوی ۲ بود → رقم کنترل باید برابر `۱۱ - باقیمانده` باشد.
   - رقم کنترل = رقم دهم (آخرین رقم سمت راست) کد ملی.

### مثال
کد ملی `0939685736`:
`(0×10)+(9×9)+(3×8)+(9×7)+(6×6)+(8×5)+(5×4)+(7×3)+(3×2) = 291`
`291 % 11 = 5` → چون `5 ≥ 2`: رقم کنترل مورد انتظار = `11 - 5 = 6` → رقم دهم واقعی `6` است → معتبر.
