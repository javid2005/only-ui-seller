### مورد ۱۲ — ریشه و درمان

`ProductPreviewCard` فقط `form.variants` (تعریفِ انتخاب‌ها) و قیمتِ سطحِ محصول را
می‌خواند و هیچ‌وقت `form.combinations` را نگاه نمی‌کرد. نتیجه: غیرفعال‌کردن مدل،
قیمت اختصاصی، موجودی اختصاصی و تصویر اختصاصی هیچ اثری در پیش‌نمایش نداشتند و
کلیک روی چیپ فقط رنگِ خودِ چیپ را عوض می‌کرد.

حالا «مدلِ انتخاب‌شده» از همان `form.combinations` حل می‌شود که جدول مدل‌ها
می‌نویسد — همان یک منبع، برای هر دو. تأیید با Playwright، نه با چشم:

```
قیمت‌گذاری مدل ۱ (۹۰۰٬۰۰۰ / ۷)  → پیش‌نمایش: ۹۰۰٬۰۰۰ تومان · موجودی ۷ عدد
کلیک چیپ «آبی»                  → پیش‌نمایش: ۱٬۲۵۰٬۰۰۰ تومان · موجودی ۳ عدد
غیرفعال‌کردن همان مدل در جدول     → پیش‌نمایش: «ناموجود» + توضیح
```
